## 🌟 Overview

**Total Solution** is a high-end digital agency website crafted to deliver an exceptional user experience. Built with a stunning dark/indigo gradient aesthetic and glassmorphism elements, it showcases professionalism and modern design trends. The platform is structured to highlight four core digital services and optimized with direct WhatsApp integrations to maximize client conversions.

## ✨ Key Features

- 🎨 **Premium UI/UX Design:** Immersive gradients (`#060c1f` to `#091128`), glassmorphism cards, and modern layout structures.
- 📱 **Fully Responsive:** Adapts flawlessly to desktop, tablet, and mobile devices using Bootstrap 5 grid systems.
- 🇮🇳 **Localized for India:** Configured with Indian Rupee (₹) budgets, Indian team members, and a Noida-based business location.
- 💬 **WhatsApp Integration:** Instant communication buttons built right into the contact page and footer using `wa.me` links.
- 🚀 **Smooth Animations:** Integrated with AOS (Animate on Scroll) for effortless fade-ins and custom CSS keyframes for floating hero elements.
- ⚡ **Performance Optimized:** No heavy loaders; clean and semantic code structure for lightning-fast page loads.

## 🚀 Setup & Installation

Follow these steps to run the website locally on your machine:

1. **Install a Local Server:** Download and install [XAMPP](https://www.apachefriends.org/), [MAMP](https://www.mamp.info/), or [WAMP](https://www.wampserver.com/).
2. **Clone the Repository:** 
   ```bash
   git clone https://github.com/yourusername/total-solution-agency.git
   ```
3. **Move to Server Directory:** Place the cloned folder inside your local server's web root directory:
   - XAMPP: `htdocs/`
   - WAMP: `www/`
   - MAMP: `htdocs/`
4. **Run the Project:** Start Apache via your local server control panel and open your browser to:
   ```text
   http://localhost/Digital-Agency
   ```
